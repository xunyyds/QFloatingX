## 安装与使用

### 推荐版本：
- 推荐QQ版本：9.3.70 
- 支持QQ版本：9.2.35 - 最新
- 推荐模块版本：1.3.4
- 支持模块版本：1.3.0 - 最新

### 安装步骤

1. **如何使用**
   - 下载整个仓库并从根目录解压`QFloatingX` 文件夹完整复制到QFun的脚本目录

2. **启用模块**
   - 打开QFun设置
   - 找到并启用QFloatingX模块

3. **使用功能**
   - **悬浮窗**: 长按悬浮球可拖拽，点击打开功能菜单
   - **长按菜单**: 长按任意消息弹出功能菜单
   - **双击消息菜单**：双击任意消息弹出功能菜单（前提在脚本设置开启开关）
